# Nexus local IDE implementation plan

Goal: a runnable local IDE with real file editing, shared evidence-backed knowledge, Codex subscription execution, official Claude Code terminal, review and test history.
Architecture: loopback-only authenticated Node service owns SQLite, file access, CLI sessions and context snapshots; React UI consumes the service. No token copying or automatic paid fallback.
Stack: Node 24 SQLite, Express, WebSocket/PTTY, React, CodeMirror, xterm, Vite.

- [x] 1. `tests/core.test.mjs`: persistence, stale evidence, cross-project opt-in, path traversal/symlink/secret rejection, optimistic file writes. Run `npm test` red, implement `server/store.mjs` and `server/files.mjs`, run green.
- [x] 2. `server/context.mjs`: deterministic shared context and immutable snapshot. Include goal, selected files/hashes, scoped notes, recent successful outputs; never credentials. Test same bundle for both adapters and stale exclusion.
- [x] 3. `server/providers.mjs`, `server/terminal.mjs`: official CLI detection and login status, bounded Codex exec with JSON events and read-only sandbox, official interactive CLI terminal. Claude requires user login. PTY shares prepared context, not hidden model state. Test argument construction, environment filtering, cancellation.
- [x] 4. `server/index.mjs`: authenticated localhost API, project tree/edit, note/edge CRUD, run history/cancel, test command log, export, terminal. Verify API authorization and origin checks. User-triggered test shell is local trusted execution, not sandboxed.
- [x] 5. `src/App.tsx`, `src/style.css`: projects/files, editor with optimistic save and diff preview, AI work panel, searchable graph/knowledge editor, accounts/terminal, execution evidence. Responsive and keyboard accessible.
- [x] 6. `tests/e2e.spec.ts`, README and launcher: real browser CRUD/edit/conflict/graph/reload/auth checks, production build, real Codex prompt against demo project, screenshot. Claude inference remains user-login-dependent and must be reported separately.

Rulings: new standalone directory rather than worktree because no source repository exists. Implement sequentially as requested; no second approval. Official CLI integrated terminal is the documented Claude subscription route; no raw Claude OAuth forwarding. Manual profile selection only; automatic quota rotation deferred until officially supported. Runtime test commands require explicit UI action, with terminal process timeout and cancellation. No pre-existing project content is ingested by default.

Verification: 18 core/API/snapshot tests pass; TypeScript check and production build pass; Chrome E2E passes with isolated fixture DB, including 390px mobile overflow check. Real Codex subscription read-only inference completed. Claude CLI is installed but not logged in. Fresh reviewer found and fixes covered subscription gates, inherited knowledge revocation, edit response races, source removal and PTY process-group cleanup.

Ruling: isolated source snapshots replace initial raw project terminal cwd; supported text copies preserve existing WIP and executable modes. Dependencies/binary assets are excluded and described in UI/README. Use official interactive Claude Code rather than unsupported token forwarding. Terminal output stays ephemeral; users explicitly save conclusions. Graph relations are navigational in v0.1; no claim of benchmark improvement.

Provider compatibility finding: preinstalled Codex 0.149.0 could run its default model but rejected the user's configured gpt-6-astra. Bundled official @openai/codex 0.163.0 without altering the global installation. Queried model/list and selected its default gpt-6.1-sol; real ChatGPT-auth inference succeeded. Interactive CLI disables hooks/plugins and enumerates only non-plugin MCP configurations before disabling them, because plugin-generated names otherwise create invalid transport overrides. This was verified to leave zero enabled external MCPs. No credentials copied.

Final live evidence: bundled Codex 0.163.0 / GPT-6.1-Sol completed both the read-only API chat and interactive official terminal context-file read with ChatGPT subscription login. Browser E2E passed after final provider changes.
