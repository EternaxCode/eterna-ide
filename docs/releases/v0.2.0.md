Eterna IDE is the public name of the original Nexus local prototype.

- Shared evidence-backed knowledge for GPT/Codex and official Claude Code terminals.
- Local editor, source snapshots, per-file change review, test execution and persistent history.
- On-demand editor/language/terminal loading, compact history summaries and conditional state requests.
- Reproducible performance fixtures and an enforced initial-bundle budget.
- MIT license, contribution/security documentation and CI.

Live verification includes ChatGPT-authenticated GPT responses and an official Codex terminal reading shared context, editing a source snapshot, and applying the reviewed change. Claude requires your own official login; live Claude inference remains unverified in the author's environment.

This is a macOS-first local beta with a Korean interface. Automatic account rotation, vector retrieval, automatic code graphs and automatic Claude-output ingestion are not included. Existing `.data/nexus.sqlite` remains compatible.
