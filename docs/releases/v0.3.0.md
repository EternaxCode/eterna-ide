Eterna is now a native Tauri 2 / Rust desktop app for macOS Apple Silicon and Windows x64.

- No localhost Node server required for desktop use.
- Read-only legacy import into separate native storage with verified backups and record/workspace integrity checks.
- SHA-256 content addressing, Zstandard compression when useful, persisted shared context manifests and scoped memory handoff.
- Source-snapshot archival/restoration that preserves unapplied changes; active sessions and Git history block unsafe archival.
- Official Codex/Claude native CLI integration, cross-platform PTY/process cancellation, and Korean progress events.
- 3D Synapse graph, real-event timeline, replay, Worker layout, bounded GPU rendering and text fallback.

macOS actual-app verification includes real ChatGPT subscription inference, legacy import with unchanged original DB hash, Korean timeline and populated WebGL rendering. Windows CI installs the NSIS package and checks the installed executable, IPC, real shell execution, persisted knowledge and populated 3D renderer. Claude requires the owner's login; live Claude inference remains unverified.

Packages are beta: macOS uses ad-hoc signing without Developer ID notarization; Windows has no commercial code-signing certificate. Official AI tools are installed separately to keep Eterna's own package small. No automatic account rotation, hidden model-thought visualization, destructive automatic GC, or vector database is included.
