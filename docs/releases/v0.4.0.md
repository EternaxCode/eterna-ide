Eterna 0.4 adds bounded shared memory and explicit development handoffs, informed by Claude Code's public memory and workflow documentation.

- Cap the shared prompt at 64KiB UTF-8, retain originals, and show omitted/excerpted items. This is not a token limit for the official CLI's entire session.
- Pin important memories without changing their verification or sharing status.
- Load scoped project AGENTS.md/CLAUDE.md instructions with size limits, and invalidate prior answers when instruction inventories change.
- Add acceptance criteria and explicit continuation of ended work. Recheck evidence and sharing revocation before reusing a bounded prior-output excerpt.
- Skip unchanged native state payloads and avoid rewriting idle run outputs. Preserve existing data and legacy prompt reconstruction.

Analysis scope: public documentation and installed CLI behavior, not proprietary desktop internals. No private Claude conversation or memory files are copied. Native and legacy web paths use the same selection and handoff rules. Existing beta signing limitations apply to macOS Apple Silicon and Windows x64 packages.
