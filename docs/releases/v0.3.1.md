Eterna IDE 0.3.1 adds provider-specific Model, Effort and permission selectors.

- Discover models and supported effort values from the installed official Codex/Claude CLI without sending an inference prompt.
- Save selections independently per provider. Reset effort when switching models, reject unsupported combinations, and provide explicit refresh/error states.
- Forward selections to Codex chat and both official coding terminals. Default permissions are full access, as requested; restricted mode remains selectable.
- Full-access Codex chat can modify the current project and execute commands. Official terminal work continues to start in a separate work copy.
- Keep existing knowledge and project data unchanged. No credential extraction or global CLI configuration changes.

macOS Apple Silicon / Windows x64 beta packages. macOS is ad-hoc signed without Developer ID notarization; Windows is not commercially code-signed. Model availability is based on the installed CLI catalog; account access and provider policy still apply.
